Ekstensi

Format yang didukung: ekstensi WebExtension (Manifest V2/V3) dalam folder ter-unpack. Electron hanya mendukung sebagian API chrome.*, jadi tidak semua ekstensi akan berfungsi. Add-on Firefox (.xpi) tidak bisa dipasang, tetapi banyak ekstensi lintas-browser punya versi folder yang bisa dimuat di sini.
Dukungan ekstensi
Ekstensi hanya bisa dimuat jika sesi memakai penyimpanan disk sementara (bukan murni di memori). Datanya dihapus saat aplikasi dibuka berikutnya. Perubahan butuh mulai ulang.
