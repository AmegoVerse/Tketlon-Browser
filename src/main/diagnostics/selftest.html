Laporan teks

Penghapusan data (cookie, localStorage, IndexedDB, Cache Storage, service worker) diuji otomatis pada setiap Reset Identity; hasilnya ada di Privacy Receipt. Uji WebRTC di sini tidak memeriksa IP publik, karena itu butuh server STUN di luar dan sengaja tidak dilakukan. Uji Canvas hanya memeriksa konsistensi, bukan penyamaran fingerprint.
